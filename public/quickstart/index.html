Pre-flight

Path 1

Computer over USB

For a laptop running photo booth software, Lightroom, tethered capture — anything with a print dialog. If your setup can print, it can print to the DS40.

  1. Install the driver first, on the machine you'll actually use.

    It comes from DNP: their download library — filter to DS40 and your OS. The current Mac build is v5.2.7. On a recent macOS, install and test the day you pick the kit up; if it won't take, the print server is the workaround.

  2. Power the printer on first, then connect USB.

    Let it finish settling before you plug into the computer. Straight into a port — hubs and daisy-chained dongles are the usual culprit when a job disappears.

  3. Set the driver's paper size to the media that's loaded.

    A 4×6 job sent to 6×8 media just sits in the queue with no error. This is the single most common setup failure — check it before you troubleshoot anything else.

  4. Send one test print.

    Before you trust the whole chain. A 4×6 lands in 8–9 seconds and comes out dry.

  5. Point your software at it.

    Most photo booth apps want the DS40 as the system default printer, with page size set to the loaded media. Set it inside the app too, not just in the OS — they don't always agree.

  6. Size your images to fill the sheet.

    Dye-sub prints edge to edge, so anything off-ratio gets cropped or comes back with white bands. Match the ratio in your template, not at the printer.

Path 2 · only if you rented it

WCM-Plus print server

Wireless printing from iPhone, iPad, Android, Mac or PC with no drivers installed anywhere. The server makes its own Wi-Fi hotspot; everyone prints to that.

  1. Printer on, media loaded, no error lights.

    Order matters here. Printer first, server second — the WCM-Plus looks for printers when it boots.

  2. Connect the WCM-Plus to the printer with the supplied USB cable.

    Any of its three USB ports works.

  3. Power the WCM-Plus from its own 5V/3A USB-C supply.

    Don't try to run it off the printer — it won't get enough current.

  4. Wait for the welcome print.

    On boot it prints a page carrying two QR codes — one joins the hotspot, one opens the portal — plus the status of the connected printer. No welcome page means it never saw the printer. Power-cycle the server, not the printer.

  5. Join the hotspot.

    Scan the first QR code, or pick in Wi-Fi settings — the last three characters are unique to this unit. Password . Accept the license the first time you connect.

  6. Print with AirPrint.

    Open the photo, tap Share on iOS or the menu icon on Android, choose Print, pick the printer and size, print. Nothing to install on anyone's phone — this is the path most guests will use without being told.

  7. Keep the portal open for everything else.

    Any browser, — printer status, remaining prints, settings, and the reprint queue. WCM Print lives there too: use it when you want to crop, straighten, add a border or fix an image before it goes through.

Do this first
Set every iPhone that will print to Most Compatible. Settings → Camera → Formats → Most Compatible. HEIC files hide their true dimensions from the server, so it can't crop to fill and the print comes back with white edges. One setting, one minute, and it's the most common complaint gone.

If a sheet comes out blank

Fix
Crop that photo to the print's aspect ratio in the Photos editor and send it again — it's a quirk of the image, not a fault in the printer. If one image keeps doing it, run that image through WCM Print in the portal instead. Android ultra-HDR shots can show the same white edges as HEIC; those go through WCM Print too.

Letting guests print themselves

  1. Turn on guest access.

    System Settings → Login & Print Services → tick WCM Print. You get a QR code to that you can print or put on a table sign.

  2. Know the tradeoff before you switch it on.

    Guests see thumbnails of every print from the session and can reprint any of them. At a wedding that's charming; at a corporate event it may not be.

  3. Set the caps.

    Defaults are 10 copies and 50 uploads per session. Adjust under System Settings → Print Settings — anywhere from 1 to 100 copies, 1 to 50 uploads.

The server only needs internet if guests are pulling photos out of iCloud or Google Photos. Networks with a sign-in or agreement page can't be used — have guests download their photos before they join the hotspot.

When something goes wrong

Read the symptom, not the manual

Nearly everything on this list is a two-minute fix if you've seen it once before.

Four blank prints after a media change normal

The printer is aligning the new roll. Let it finish and don't open the drawer.

Red error light after loading media seating

Reseat both the paper and the ribbon cassette, then close the drawer. That clears it almost every time.

Printer does nothing at all scrap box

The DS40 will not operate without the scrap box in place. Pull it and reseat it.

Paper jam feed

Open the media drawer, release the paper compartment lever, remove the scrap box, lift the roll out and pull any paper still inside. Cut the damaged paper off straight across with scissors — a crooked cut jams again immediately. Refeed from the bottom of the compartment until the printer beeps, replace the scrap box, close it up. It cycles its lights and prints four blanks when it's aligned.

Torn ribbon snag

Pull the cassette, cut the ribbon clean, tape the two ends with cellophane tape, wind it on until the tape is out of sight, take up all slack, reinstall with the supply side to the front.

Runs hot or keeps pausing vents

Power down, disconnect the cables, dust the ventilation area on the back, give it 4 in. of clearance. Dye-sub throws real heat at volume.

Prints have white edges HEIC / ultra-HDR

iPhone: Settings → Camera → Formats → Most Compatible. Android ultra-HDR does the same thing. Either way you can also resize the image in WCM Print's edit tool before sending it.

Blank sheet came out image, not printer

Crop that photo to the print's aspect ratio in the Photos editor and resend. If one image keeps doing it, run it through WCM Print in the portal instead.

No printer listed in the portal boot order

The WCM-Plus came up before the printer did. Leave the printer on and power-cycle the server.

Job sits in the queue, nothing prints size mismatch

The driver's paper size doesn't match the loaded media. Change the driver setting, clear the queue, resend.

Media
Always replace paper and ribbon together. They're engineered to run out at the same time; swapping one without the other causes jams and error lights. If you're supplying your own, it has to be a DS40 media set for the size you're printing.

Wrapping up

Returning the kit

  • Leave the media in the printer. Don't unload it.
  • Printer, power cable and USB cable back in the case.
  • WCM-Plus, its USB-C power supply and its printer cable, if you rented the server.
  • Flag anything that went sideways, even if it seems fine now.
